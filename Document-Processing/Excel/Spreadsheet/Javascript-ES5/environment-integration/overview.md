# Environment Integration in JavaScript Spreadsheet

The JavaScript Spreadsheet component can be integrated into various development environments and platforms. This section provides guides for setting up the Spreadsheet in different frameworks and environments.

## Supported Environments

The JavaScript Spreadsheet component supports integration with:

- **Plain HTML**: Direct integration in HTML applications
- **npm-based setups**: Integration in Node Package Manager-based projects
- **Module loaders**: Support for various module loading systems
- **CDN usage**: Integration using Content Delivery Networks

## Overview of Integration Options

The JavaScript Spreadsheet component provides documentation and samples for integrating with various environments:

- **Getting Started Guides**: Setup instructions for different environments
- **Framework Integration**: Integration with popular JavaScript frameworks
- **Build Tool Integration**: Integration with webpack, Rollup, and other build tools
- **Deployment Options**: Guidance on deploying Spreadsheet applications

# Freeze Pane in JavaScript Spreadsheet

Freeze panes allow you to keep specific rows or columns visible while scrolling through the worksheet. This is particularly useful when working with large spreadsheets where you want to maintain visibility of header rows or columns.

For detailed information about freeze pane functionality, refer to the [Freeze Pane documentation](../freeze-pane).

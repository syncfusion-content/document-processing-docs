# Open Excel Files in JavaScript Spreadsheet

The JavaScript Spreadsheet component allows you to open Excel files from various sources. You can open files from local storage, URL endpoints, or other data sources.

## Overview of Open File Operations

The JavaScript Spreadsheet component provides features for opening files:

- **[Open Excel Files](#open)**: Open Excel documents using the UI or programmatically.
- **[Open from URL](#open-url)**: Load Excel files from web endpoints.
- **[Open from JSON](#open-json)**: Load spreadsheet data from JSON format.

For detailed information about open file operations, refer to the [Open and Save documentation](../open-save#open).

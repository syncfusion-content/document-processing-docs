# Save Excel Files in JavaScript Spreadsheet

The JavaScript Spreadsheet component allows you to save spreadsheets in various formats and locations. You can save files to local storage, download them, or send them to a server for processing.

## Overview of Save File Operations

The JavaScript Spreadsheet component provides features for saving files:

- **[Save Excel Files](#save)**: Save spreadsheet data using the UI or programmatically.
- **[Save to JSON](#save-json)**: Export spreadsheet data in JSON format.
- **[Save as Different Format](#save-format)**: Save in different file formats.

For detailed information about save file operations, refer to the [Open and Save documentation](../open-save#save).

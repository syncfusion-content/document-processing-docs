# Images and Illustrations in JavaScript Spreadsheet

The JavaScript Spreadsheet component allows you to insert images directly into worksheet cells to enhance visual presentation and provide additional context alongside data. Images such as logos, screenshots, diagrams, or illustrations can be placed within a sheet, positioned as needed, resized, selected, or removed.

Images can be controlled using the [allowImage](https://ej2.syncfusion.com/javascript/documentation/api/spreadsheet/index-default#allowimage) property, which is enabled by default.

## Overview of Images and Illustrations Operations

The JavaScript Spreadsheet component also provides a range of features for working with images and illustrations. Below is a quick overview of each feature, with links to their respective documentation sections:

- **[Insert and Position Images](#insert-image)**: Add images to your spreadsheet and place them at the desired location.
- **[Delete Images](#delete-image)**: Remove images that are no longer required from your spreadsheet.
- **[Image Management](#image-management)**: Manage image properties and customize appearance.

For comprehensive information about illustrations including charts and image operations, refer to the [Illustrations documentation](../illustrations).

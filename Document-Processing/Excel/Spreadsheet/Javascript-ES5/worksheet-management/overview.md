# Worksheet Management in JavaScript Spreadsheet

Worksheet management in the JavaScript Spreadsheet component provides comprehensive features for managing multiple sheets within a workbook.

## Overview of Worksheet Operations

The JavaScript Spreadsheet component provides a variety of features for managing worksheets. Below is a quick overview of each feature, with links to their respective documentation sections:

- **[Insert Sheet](#insert-sheet)**: Add new worksheets to your workbook.
- **[Delete Sheet](#delete-sheet)**: Remove unwanted worksheets from your workbook.
- **[Rename Sheet](#rename-sheet)**: Change the name of worksheets for better organization.
- **[Move Sheet](#move-sheet)**: Reorder worksheets within the workbook.
- **[Duplicate Sheet](#duplicate-sheet)**: Create copies of existing worksheets.
- **[Sheet Visibility](#sheet-visibility)**: Control the visibility of worksheets (hide/show).
- **[Headers and Gridlines](#headers-gridlines)**: Toggle the visibility of row/column headers and gridlines.

For detailed information about worksheet operations, refer to the [Worksheet documentation](../worksheet).

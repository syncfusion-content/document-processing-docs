# Cell Ranges and Operations in JavaScript Spreadsheet

A group of cells in a sheet is known as a cell range. The JavaScript Spreadsheet component provides several features for managing and manipulating cell ranges efficiently.

## Overview of Cell Range Operations

The JavaScript Spreadsheet component provides a variety of features for working with cell ranges. Below is a quick overview of each feature, with links to their respective documentation sections:

- **[Editing](./editing)**: Enter, modify, and update cell values directly in the spreadsheet.
- **[Wrap Text](./wrap-text)**: Display large content as multiple lines within a single cell.
- **[Merge Cells](./merge-cells)**: Combine two or more cells into a single cell.
- **[Clipboard Operations](./clipboard)**: Cut, copy, and paste cell data efficiently.
- **[Autofill](./autofill)**: Fill cells with data based on patterns from adjacent cells.
- **[Clear](./clear)**: Remove cell contents or formatting from selected ranges.

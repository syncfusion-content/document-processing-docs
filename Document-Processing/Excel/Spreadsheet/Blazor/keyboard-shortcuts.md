# Keyboard shortcuts in Blazor Spreadsheet

The Blazor Spreadsheet supports keyboard shortcuts for performing clipboard, undo and redo, selection, navigation, editing, and other operations.

<b>Formatting</b>

| Windows | MAC | Actions |
|-----|----- | -----|
| <kbd>Ctrl</kbd> + <kbd>B</kbd> | <kbd>⌘</kbd> + <kbd>B</kbd> | Applies or removes bold formatting from the selected cells. |
| <kbd>Ctrl</kbd> + <kbd>U</kbd> | <kbd>⌘</kbd> + <kbd>U</kbd> | Applies or removes underline formatting from the selected cells. |
| <kbd>Ctrl</kbd> + <kbd>I</kbd> | <kbd>⌘</kbd> + <kbd>I</kbd> | Applies or removes italic formatting from the selected cells. |
| <kbd>Ctrl</kbd> + <kbd>5</kbd> | <kbd>⌘</kbd> + <kbd>5</kbd> | Applies or removes strikethrough formatting from the selected cells. |

<b>Autofill</b>

| Windows | MAC | Actions |
|-----|----- | -----|
| <kbd>Ctrl</kbd> + <kbd>D</kbd> | <kbd>⌘</kbd> + <kbd>D</kbd> | Fills the selected cells down. |
| <kbd>Ctrl</kbd> + <kbd>R</kbd> | <kbd>⌘</kbd> + <kbd>R</kbd> | Fills the selected cells right. |

<b>Clipboard</b>

| Windows | MAC | Actions |
|-----|----- | -----|
| <kbd>Ctrl</kbd> + <kbd>C</kbd> | <kbd>⌘</kbd> + <kbd>C</kbd> | Copies the selected cells to the clipboard. |
| <kbd>Ctrl</kbd> + <kbd>X</kbd> | <kbd>⌘</kbd> + <kbd>X</kbd> | Cuts the selected cells to the clipboard. |
| <kbd>Ctrl</kbd> + <kbd>V</kbd> | <kbd>⌘</kbd> + <kbd>V</kbd> | Pastes the clipboard content into the Spreadsheet. |

<b>Undo/Redo</b>

| Windows | MAC | Actions |
|-----|----- | -----|
| <kbd>Ctrl</kbd> + <kbd>Z</kbd> | <kbd>⌘</kbd> + <kbd>Z</kbd> | Reverses the last action performed. |
| <kbd>Ctrl</kbd> + <kbd>Y</kbd> | <kbd>⌘</kbd> + <kbd>Y</kbd> | Reapplies the last action that was undone. |

<b>Selection</b>

| Windows | MAC | Actions |
|-----|----- | -----|
| <kbd>Shift</kbd> + <kbd>Arrow Keys</kbd> | <kbd>⇧</kbd> + <kbd>Arrow Keys</kbd> | Extends the current selection in the direction of the arrow key. |
| <kbd>Ctrl</kbd> + <kbd>A</kbd> | <kbd>⌘</kbd> + <kbd>A</kbd> | Selects all cells in the current worksheet. |
| <kbd>Ctrl</kbd> + <kbd>Space</kbd> | <kbd>⌘</kbd> + <kbd>Space</kbd> | Selects the active column. |
| <kbd>Shift</kbd> + <kbd>Space</kbd> | <kbd>⇧</kbd> + <kbd>Space</kbd> | Selects the active row. |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Space</kbd> | <kbd>⌘</kbd> + <kbd>⇧</kbd> + <kbd>Space</kbd> | Selects all cells in the worksheet. |

<b>Navigation</b>

| Windows | MAC | Actions |
|-----|----- | -----|
| <kbd>Arrow keys</kbd> | <kbd>Arrow keys</kbd> | Navigates between adjacent cells in the direction of the arrow key. |
| <kbd>Enter</kbd> | <kbd>Enter</kbd> | Moves the active cell down one row. |
| <kbd>Shift</kbd> + <kbd>Enter</kbd> | <kbd>⇧</kbd> + <kbd>Enter</kbd> | Moves the active cell up one row. |
| <kbd>Tab</kbd> | <kbd>Tab</kbd> | Moves the active cell right one column. |
| <kbd>Shift</kbd> + <kbd>Tab</kbd> | <kbd>⇧</kbd> + <kbd>Tab</kbd> | Moves the active cell left one column. |
| <kbd>Page Up</kbd> | <kbd>Page Up</kbd> | Moves up one screen at a time. |
| <kbd>Page Down</kbd> | <kbd>Page Down</kbd> | Moves down one screen at a time. |
| <kbd>Ctrl</kbd> + <kbd>Home</kbd> | <kbd>⌘</kbd> + <kbd>Home</kbd> | Moves to the first cell in the current row. |
| <kbd>Ctrl</kbd> + <kbd>End</kbd> | <kbd>⌘</kbd> + <kbd>End</kbd> | Moves to the last used cell. |
| <kbd>Ctrl</kbd> + <kbd>Arrow Keys</kbd> | <kbd>⌘</kbd> + <kbd>Arrow Keys</kbd> | Moves to the edge of the current data region. |

<b>Editing</b>

| Windows | MAC | Actions |
|-----|----- | -----|
| <kbd>F2</kbd> | <kbd>F2</kbd> | Enters edit mode for the selected cell. |
| <kbd>Enter</kbd> | <kbd>Enter</kbd> | Confirms the edit and moves the active cell down one row. |
| <kbd>Shift</kbd> + <kbd>Enter</kbd> | <kbd>⇧</kbd> + <kbd>Enter</kbd> | Confirms the edit and moves the active cell up one row. |
| <kbd>Tab</kbd> | <kbd>Tab</kbd> | Confirms the edit and moves the active cell right one column. |
| <kbd>Shift</kbd> + <kbd>Tab</kbd> | <kbd>⇧</kbd> + <kbd>Tab</kbd> | Confirms the edit and moves the active cell left one column. |
| <kbd>Escape</kbd> | <kbd>Esc</kbd> | Cancels the edit and restores the cell's original value. |

<b>Clear</b>

| Windows | MAC | Actions |
|-----|----- | -----|
| <kbd>Delete</kbd> | <kbd>Delete</kbd> | Clears the contents of the selected cells. |

<b>Hyperlink</b>

| Windows | MAC | Actions |
|-----|----- | -----|
| <kbd>Ctrl</kbd> + <kbd>Click</kbd> | <kbd>⌘</kbd> + <kbd>Click</kbd> | Opens the link in the selected cell. |
| <kbd>Ctrl</kbd> + <kbd>K</kbd> | <kbd>⌘</kbd> + <kbd>K</kbd> | Opens the hyperlink dialog to insert a new link or edit an existing one. |

<b>File operations</b>

| Windows | MAC | Actions |
|-----|----- | -----|
| <kbd>Ctrl</kbd> + <kbd>O</kbd> | <kbd>⌘</kbd> + <kbd>O</kbd> | Opens a workbook file. |
| <kbd>Ctrl</kbd> + <kbd>S</kbd> | <kbd>⌘</kbd> + <kbd>S</kbd> | Saves the workbook. |

<b>Worksheet</b>

| Windows | MAC | Actions |
|-----|----- | -----|
| <kbd>Shift</kbd> + <kbd>F11</kbd> | <kbd>Shift</kbd> + <kbd>F11</kbd> | Adds a new worksheet. |

<b>Filtering</b>

| Windows | MAC | Actions |
|-----|----- | -----|
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>L</kbd> | <kbd>⌘</kbd> + <kbd>⇧</kbd> + <kbd>L</kbd> | Opens the filter dialog. |

<b>Find and Replace</b>

| Windows | MAC | Actions |
|-----|----- | -----|
| <kbd>Ctrl</kbd> + <kbd>F</kbd> | <kbd>⌘</kbd> + <kbd>F</kbd> | Opens the Find and Replace dialog. |

N> The <kbd>Command</kbd> and <kbd>Control</kbd> keys on Mac devices can be interchanged. When this switch occurs, use the <kbd>Command</kbd> key in place of the <kbd>Control</kbd> key for the above-listed key interactions on Mac devices.

# Keyboard shortcuts in Blazor Spreadsheet

The keyboard shortcuts supported in the Blazor Spreadsheet are listed below.

| Shortcut | Description |
|----------|-------------|
| `Ctrl + B` | Applies or removes bold formatting. |
| `Ctrl + U` | Applies or removes underline formatting. |
| `Ctrl + I` | Applies or removes italic formatting. |
| `Ctrl + 5` | Applies or removes strikethrough formatting. |
| `Ctrl + D` | Fills the selected cells downward. |
| `Ctrl + R` | Fills the selected cells to the right. |
| `Ctrl + C` | Copies the selected cells. |
| `Ctrl + X` | Cuts the selected cells. |
| `Ctrl + V` | Pastes the copied or cut content into the selected range. |
| `Ctrl + Z` | Reverses the most recent action. |
| `Ctrl + Y` | Repeats the most recently reversed action. |
| `Arrow keys` | Moves between cells. |
| `Shift + Arrow keys` | Extends the selection in the direction of the arrow key. |
| `Tab` / `Shift + Tab` | Moves to the next or previous cell. |
| `Enter` / `Shift + Enter` | Moves to the cell below or above. |
| `Ctrl + G` | Opens the Go To dialog to navigate to a specified cell or range. |
| `Ctrl + End` | Moves to the last used cell in the worksheet. |
| `Ctrl + Arrow keys` | Moves to the edge of the current data region. |
| `Ctrl + A` | Selects the current data region. Pressing it again selects all cells in the worksheet. |
| `Ctrl + Spacebar` | Selects the entire column of the active cell. |
| `Shift + Spacebar` | Selects the entire row of the active cell. |
| `F2` | Enables edit mode for the active cell. |
| `Esc` | Cancels edit mode and discards the changes. |
| `Delete` | Clears the content of the selected cells. |
| `Ctrl + O` | Opens the dialog to open a workbook file. |
| `Ctrl + S` / `Alt + F2` | Saves or exports the workbook. |
| `Ctrl + K` | Opens the Insert Hyperlink dialog. If the selected cell contains a hyperlink, it opens the Edit Hyperlink dialog. |
| `Shift + F11` | Inserts a new worksheet. |
| `Alt + Down Arrow` | Opens the filter UI. |

# Formula Bar in JavaScript ES6 Spreadsheet

The formula bar is used to enter or edit cell data more easily. By default, the formula bar is enabled in the spreadsheet. Use the [`showFormulaBar`](https://ej2.syncfusion.com/javascript/documentation/api/spreadsheet#showformulabar) property to enable or disable the formula bar.

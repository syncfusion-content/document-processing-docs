# Form Controls Overview

Form Controls are interactive elements that can be embedded in Excel worksheets to create fillable forms and interactive data entry templates. The ASP.NET MVC Spreadsheet component supports three types of form controls:

## Supported Form Controls

1. **Check Box** - Allow users to toggle between checked and unchecked states
2. **Radio Button** - Allow users to select one option from a group
3. **Combo Box (Dropdown)** - Allow users to select from a predefined list of options

Each form control can be linked to a specific cell to automatically update values based on user interactions.

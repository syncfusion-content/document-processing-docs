# TypeScript Spreadsheet

The Spreadsheet component is a powerful, lightweight, and versatile JavaScript spreadsheet library built for the TypeScript framework. It allows you to create, edit, and manage spreadsheets directly in your web applications.

## Key Features

- **Form Controls**: Add interactive form controls like checkboxes, radio buttons, and dropdown lists to your spreadsheets
- **Data Manipulation**: Easily work with data binding, formulas, and calculations
- **Excel Import/Export**: Import and export Excel files seamlessly
- **Collaboration**: Support for collaborative editing features
- **Performance**: Optimized for high performance and responsiveness

## Supported Components

### Form Controls

The Spreadsheet component provides built-in form controls that enable users to add interactive elements within a worksheet. Learn more about [Form Controls](form-controls) feature.

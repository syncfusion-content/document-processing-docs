# Where Can the Generated Chunks Be Used?

Chunks generated by the Syncfusion<sup>®</sup> .NET Document Chunking Library can be used in the following workflows:

- Embedding generation
- Semantic search
- Vector indexing
- Hybrid search
- Document question answering
- Grounded AI responses
- Citation-based retrieval
- Retrieval-Augmented Generation (RAG)

The chunk content can be sent to an embedding model or indexed in a search service or vector database. The metadata can be used to filter and organize the indexed content, while citations can be retained to trace each chunk to its original location and display source references in the application.

N> Integrations with embedding models, search services, vector databases, and AI models must be implemented separately.

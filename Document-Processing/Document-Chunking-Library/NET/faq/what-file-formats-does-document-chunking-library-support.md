# What File Formats Does Document Chunking Library Support?

The Syncfusion<sup>®</sup> .NET Document Chunking Library supports Excel, Word, PDF, PowerPoint, and Markdown documents.

The following table lists the supported document formats and file extensions.

<table>
<tr>
<th>Format</th>
<th>Extensions</th>
</tr>
<tr>
<td>Excel</td>
<td><code>.xlsx</code>, <code>.xls</code>, <code>.xlsm</code>, <code>.xlsb</code></td>
</tr>
<tr>
<td>Word</td>
<td><code>.docx</code>, <code>.doc</code></td>
</tr>
<tr>
<td>PDF</td>
<td><code>.pdf</code></td>
</tr>
<tr>
<td>PowerPoint</td>
<td><code>.ppt</code>, <code>.pptx</code>, <code>.pptm</code>, <code>.potx</code></td>
</tr>
<tr>
<td>Markdown</td>
<td><code>.md</code></td>
</tr>
</table>

N> When processing a document from a stream, provide the file name with the correct extension. The library uses the extension to identify the source document format.

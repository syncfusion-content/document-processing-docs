# About Syncfusion® JavaScript PowerPoint Library

The `JavaScript PowerPoint Library` is a lightweight, high-performance non-UI library written natively in JavaScript for creating, reading, and editing Microsoft PowerPoint presentations in both Node.js and browser environments. It enables developers to integrate robust PowerPoint functionality into their applications without any dependency on Microsoft Office or Microsoft Office COM libraries.

The `JavaScript PowerPoint Library` supports programmatic creation and modification of PowerPoint presentations with rich content, including slides, shapes, text, paragraphs, tables, images, and charts.

## Key features

The following are the key features of the `JavaScript PowerPoint Library`.

* Create PowerPoint presentations from scratch.
* Open, modify, and save existing presentations.
* Add slides using predefined slide layout types equivalent to Microsoft PowerPoint.
* Remove slides by instance or by index position in the slide collection.
* Customize and access master and layout slides with backgrounds, positioning, and theme control.
* Open and work with password-protected presentations.
* Create and modify sections to organize slides.
* Add and format paragraphs with bullets and numberings within text boxes and shapes.
* Add text with different formatting into a single paragraph using TextParts.
* Access and modify text formatting, hyperlinks, and text content.
* Create and edit speaker notes for slides.
* Remove paragraphs from the text body of a shape.
* Add and manipulate AutoShapes with fill and line styles, position and size precisely.
* Add, replace, and remove pictures in slides.
* Iterate through shapes to detect their kind.
* Remove shapes from a slide by instance.
* Create and edit tables by adding, appending, and inserting rows or columns.
* Format table borders to present structured data clearly.
* Remove tables from a slide.
* Create charts from scratch and edit chart data.
* Customize chart elements such as titles, chart area, plot area, series, legends, data labels, and axes.
* Refresh charts to reflect actual data.
* Remove charts from a slide.

## Supported environments

The JavaScript PowerPoint Library supports the following application environments:

* Node.js
* JavaScript
* TypeScript
* Angular
* React
* Vue

N> 1. The current version of the JavaScript PowerPoint Library supports the .PPTX file format.

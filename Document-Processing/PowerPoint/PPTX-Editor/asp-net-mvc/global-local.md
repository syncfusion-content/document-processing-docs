# Globalization and Localization in ASP.NET MVC PPTX Editor

## Localization

The [`Localization`](https://ej2.syncfusion.com/aspnetmvc/documentation/common/localization) library allows you to localize the default text content of the PPTX Editor. The ASP.NET MVC PPTX Editor component has static text on some features (such as the ribbon, status bar, notes pane, slide show, and dialogs) that can be changed to other cultures (Arabic, German, French, and more) by defining the locale value and translation object.

> Refer the [Locale](https://github.com/syncfusion/ej2-locale).

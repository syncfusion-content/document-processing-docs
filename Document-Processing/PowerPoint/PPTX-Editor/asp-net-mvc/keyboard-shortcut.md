# Keyboard Shortcuts in ASP.NET MVC PPTX Editor

The PPTX Editor component provides built-in keyboard shortcuts to navigate presentations, perform common editing actions, control slideshows, and adjust slide magnification quickly without using the mouse or ribbon interface.

Users can access the **Keyboard Shortcuts** help dialog at any time by navigating to the **Help** tab in the ribbon and selecting **Keyboard Shortcuts** (or via the `openKeyboardShortcuts()` method).

The following table lists the supported keyboard shortcuts along with their actions in the ASP.NET MVC PPTX Editor:

| Action | Shortcut |
| --- | --- |
| Next slide | Right Arrow / Down Arrow / Page Down |
| Previous slide | Left Arrow / Up Arrow / Page Up |
| First / last slide | Home / End |
| Zoom in / out / reset | Ctrl or Command + / - / 0 |
| Start From Beginning | F5 |
| From Current Slide | Shift+F5 |
| Exit Slide Show | Esc |
| Copy | Ctrl+C |
| Undo | Ctrl+Z |
| Redo | Ctrl+Y |
| Find | Ctrl+F |

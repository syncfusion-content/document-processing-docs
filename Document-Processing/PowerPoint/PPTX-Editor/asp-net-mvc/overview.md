# About Syncfusion ASP.NET MVC PPTX Editor Control

The Syncfusion<sup style="font-size:70%">&reg;</sup> PPTX Editor is an interactive component for viewing and printing PowerPoint presentations with a familiar Microsoft PowerPoint-like interface. It can be hosted in an ASP.NET MVC 5 Razor view using JavaScript initialization and works without Microsoft Office dependencies.

N> This integration uses the JavaScript component. The `Syncfusion.EJ2.MVC5` package at version `35.1.46` does not provide a PPTX Editor HTML helper. See the [getting-started guide](./getting-started) for the MVC view and layout configuration.

The features described here focus on presentation viewing and printing, consistent with the React, Angular, and TypeScript PPTX Editor components.

## Key features

* **Document elements and formatting** – View PPTX presentations containing the following elements:
    * **Textboxes and placeholders** – Display textboxes and placeholders with their content and formatting.
    * **Basic auto-shapes** – Render basic auto-shapes with fill and outline formatting.
    * **Images** – Display images embedded in slides.
    * **Tables** – Display tables with their content and formatting.
    * **Paragraph and text formatting** – Display alignment, indentation, bold, italic, underline, font, size, and color.
* **Viewer ribbon interface** – Access viewing commands through a familiar, tab-based interface.
* **Slide navigation** – Navigate between slides using thumbnails, touch, keyboard, and mouse interactions.
* **Zoom** – Zoom in and out of a presentation.
* **Slideshow mode** – Present slides in full-screen mode.
* **Slide notes** – View notes associated with each slide.
* **Presenter view** – Use speaker notes while presenting.
* **Print** – Print the presentation with the default print settings.

## Getting started

Follow the [ASP.NET MVC getting-started guide](./getting-started) to configure the Razor layout, register a client-side license key, initialize the JavaScript component, and open a PPTX presentation.

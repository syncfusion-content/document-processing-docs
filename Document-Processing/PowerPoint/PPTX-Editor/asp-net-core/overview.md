# About Syncfusion ASP.NET Core PPTX Editor Control

The Syncfusion<sup style="font-size:70%">&reg;</sup> ASP.NET Core PPTX Editor is an interactive component for viewing and printing PowerPoint presentations with a familiar Microsoft PowerPoint-like interface. It can be added to Razor Pages and works without Microsoft Office dependencies.

## Key features

* **Document elements and formatting** – View PPTX presentations containing the following elements:
    * **Textboxes and placeholders** – Display textboxes and placeholders with their content and formatting.
    * **Basic auto-shapes** – Render basic auto-shapes with fill and outline formatting.
    * **Images** – Display images embedded in slides.
    * **Tables** – Display tables with their content and formatting.
    * **Chart** – Supports charts rendered in the slides.
    * **Paragraph and text formatting** – Display alignment, indentation, bold, italic, underline, font, size, and color.
* **Viewer ribbon interface** – Access viewing commands through a familiar, tab-based interface.
* **Slide navigation** – Navigate between slides using thumbnails, touch, keyboard, and mouse interactions.
* **Zoom** – Zoom in and out of a presentation.
* **Slideshow mode** – Present slides in full-screen mode.
* **Slide notes** – View notes associated with each slide.
* **Presenter view** – Use speaker notes while presenting.
* **Print** – Print the presentation with the default print settings.

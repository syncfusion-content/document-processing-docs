# Notes in Vue PPTX Editor

The Notes pane displays the notes associated with the currently selected slide. It is integrated into the PPTX Editor and is available by default without requiring any additional configuration. Users can view slide-specific notes while navigating through the presentation, and the displayed content automatically updates when a different slide is selected. The Notes pane can be accessed from both the View tab and the Notes button available in the status bar. If a slide does not contain notes, the pane indicates that no notes are available for that slide.

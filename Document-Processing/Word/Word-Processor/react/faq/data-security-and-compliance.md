# FAQs about data security and compliance in React DOCX Editor

The frequently asked questions about data security and compliance in [React DOCX Editor](https://www.syncfusion.com/docx-editor-sdk/react-docx-editor) (Document Editor) are listed below:

## Does the Syncfusion DOCX Editor SDK Access, Store, or Transmit Customer Data?

No. The Syncfusion DOCX Editor SDK is designed to run within your own environment, including the browser, your servers, or self-hosted infrastructure. Syncfusion does not access, process, store, transmit, retain, or otherwise have access to customer document data.

## Does Syncfusion DOCX Editor SDK Use AI or Customer Data for Model Training?

No. The DOCX Editor SDK does not use AI, ML, Generative AI, or LLMs as part of its functionality. Customer data is not used to train, improve, fine-tune, validate, or test AI models. Additionally, AI is not used in the delivery or operation of the DOCX Editor SDK.

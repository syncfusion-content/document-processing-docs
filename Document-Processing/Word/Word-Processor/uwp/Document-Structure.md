# Document structure in UWP RichTextBox

The [`SfRichTextBoxAdv`](https://help.syncfusion.com/cr/uwp/Syncfusion.SfRichTextBoxAdv.SfRichTextBoxAdv.html) control exposes the underlying Word document as a tree of elements: the document contains one or more sections; each section contains blocks (paragraphs and tables); and each paragraph contains inlines (text, fields, pictures, and so on). The following illustration shows the high-level document structure.

![Document structure overview](Document-Structure_images/Document-Structure_img1.jpeg)

N> The document-structure APIs are supported from Syncfusion UWP RichTextBox v17.4.0.X onwards.

## FAQs about Angular DOCX Editor

The frequently asked questions about [Angular DOCX Editor](https://www.syncfusion.com/docx-editor-sdk/angular-docx-editor) (Document Editor) are listed below:

## Whether the Java helper JARs (syncfusion-ej2-wordprocessor, syncfusion-docio) are covered by the DOCX Editor SDK license or require a Document SDK license as well?

The `syncfusion-ej2-wordprocessor` JAR is a DOCX Editor-specific component and is covered by the DOCX Editor SDK license.

The `syncfusion-docio` JAR is also covered by the DOCX Editor SDK license when it is used for DOCX Editor-related operations, such as document import, export, and conversion. However, if `syncfusion-docio` is used independently for general Word document processing, such as creating, editing, merging, splitting, or mail merge operations outside the DOCX Editor workflow, we recommend obtaining a Syncfusion Document SDK license.

For more information, refer to [Available Syncfusion Java Packages](../../../Word-Library/java/Installation/available-syncfusion-java-packages.md)

## Does the DOCX Editor SDK license cover Word document processing using the Syncfusion Word Library in server-side environments?

The DOCX Editor SDK license covers Word document processing using the Syncfusion Word Library (DocIO) when it is performed as part of the DOCX Editor workflow. This includes operations such as document import, export, conversion, protection, and other processing required to support the DOCX Editor.

If Word document processing is performed independently outside the DOCX Editor workflow, an appropriate Syncfusion Document SDK license is required.

# Supported file formats in JavaScript Word Library

Syncfusion<sup>&reg;</sup> [JavaScript Word Library](https://www.syncfusion.com/document-sdk/javascript-word-library) supports native file formats of Microsoft Word, such as DOCX, DOTX, DOCM, and DOTM. It also supports import HTML format.
